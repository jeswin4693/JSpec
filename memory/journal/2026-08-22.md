### Verified findings about Spec Kit (fetched, current)

CLI `specify-cli`, installed via `uv`. Commands are `speckit.`-prefixed:
`constitution`, `specify`, `clarify`, `plan`, `tasks`, `checklist`, `analyze`,
`implement`, `converge`, `taskstoissues`. Creates `.specify/` + `specs/`.
Customisation via **extensions** (new commands), **presets** (modified workflow),
**bundles** (role-based team provisioning). 30+ agent integrations.

Four things upstream has that Polaris dropped or never deployed: `clarify`,
`converge` (spec-vs-code drift — the "drift detector" idea already exists),
`analyze`, and role bundles.

### Verified Claude Code mechanics (fetched)

- **Plugins**: `.claude-plugin/plugin.json` + `skills/`, `agents/`, `hooks/`,
  `.mcp.json`, `.lsp.json`, `monitors/`, `bin/`, `settings.json` at plugin root
  (**not** inside `.claude-plugin/`). Skills namespaced `/plugin:skill`.
  Test with `--plugin-dir`, reload with `/reload-plugins`, validate with
  `claude plugin validate`. Marketplaces can be **private repos**. Enterprise
  **managed settings can force-enable** a plugin org-wide.
- **Skills are model-invoked** by default; `disable-model-invocation: true`
  makes one deliberate-only. This is the mechanism behind D-008.
- **`monitors/`** pushes background events (log tails, CI status) into the session.
- **`bin/`** puts executables on the Bash tool's PATH — the Python core can ship
  inside the plugin.
- **Headless**: `claude -p --output-format json --json-schema '<schema>'` returns
  validated data in `structured_output`, plus `total_cost_usd` and a per-model
  cost breakdown. **`--bare` does NOT use subscription login** — it needs
  `ANTHROPIC_API_KEY`, so it is unusable here and forbidden.
